# absentee-ballot
To run this: run the 'absentee_ballot.html' file 
To look at the code: open mapdata.js

I'm really happy with how this turned out! It lists everything you need to know to get an absentee ballot as an MHC student. I learned a lot about what you need to get ballots in different states. It was really interesting to see how not all states require registration to vote (only North Dakota doesn't require voter registration). Other states automatically register you to vote. 

If I had more time, I would like to have linked the forms necessary directly into the interactive map. Right now, this map is only meant to be hovered over. If it is clicked on, it will open up to the simplemaps.com website.
